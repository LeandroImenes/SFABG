Simulação

A seguir, existe um botao de download que contém uma simulação completa dos raios Alfa (α), Beta (β) e Gama (γ).

Linguagem

A simulação foi feita 100% na linguagem C++, utilizando o VS code como compilador.

Como Executar

Para executar a simulação, basta baixar, descompactar e executar o arquivo main.exe. Para alterar para o raio desejado, pressione a tecla espaço. O arquivo main.cpp é o script. Sinta-se livre para dar uma olhada!
